EMBED SUITE 1.0.0

Xibalba v1.0.0 · Bruce + TEH-Link v3 · T-Embed CC1101 Plus · UI dispositivo en español

Requisitos: Teléfono Android 12 o superior (API 31+), cable USB OTG, LilyGO T-Embed CC1101 Plus.

Firmware: Xibalba v1.0.0 — xibalba-t-embed-cc1101.bin merged @ 0x0.

Conexión: USB OTG (prioritario). Emparejamiento TEH-Link: botón lateral ~2 s (ventana 120 s).

Perfiles: XIBALBA (Xibalba + TEH-Link) · UNKNOWN (stock Bruce sin TEH-Link — funcionalidad limitada).

Uso RF/IR/NFC solo en entornos autorizados. Eres responsable del cumplimiento legal.

1. Arquitectura TEH-Link v3

JSON NDJSON línea a línea entre app y firmware. Comandos base:

  • ping, pair, get_info, get_status
  • open_plugin, back_to_menu, list_actions
  • run_action — ejecuta acciones de plugins Xibalba
  • ota_begin / ota_chunk / ota_finish — OTA USB
  • clear_coredump — borra coredump tras reset anormal
{"cmd":"run_action","id":1,"plugin_id":"subghz_analyzer","action":"capture_start","params":{"seconds":30}}

Estado de enlace, batería, pantalla del T-Embed, accesos rápidos a plugins.
