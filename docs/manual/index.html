EMBED SUITE 4.1.0

Xibalba Native · T-Embed CC1101 Plus · Protocolo TEH-Link (JSON NDJSON por USB CDC)

Hardware: LilyGO T-Embed CC1101 Plus con firmware te-embed-xibalba.

Conexión: USB OTG (recomendado y prioritario). WiFi/BLE TEH-Link son experimentales. Emparejamiento: mantén pulsado el botón lateral ~2 s (ventana 120 s).

Uso RF/IR/NFC solo en entornos autorizados. Eres responsable del cumplimiento legal.

1. Arquitectura TEH-Link

La app habla JSON línea a línea con el firmware. Comandos base:

  • ping, pair, get_info, get_status
  • open_plugin, back_to_menu, list_actions
  • run_action — ejecuta acciones de plugins Xibalba
  • ota_begin / ota_chunk / ota_finish — actualización USB
{"cmd":"run_action","id":1,"plugin_id":"subghz_analyzer","action":"capture_start","params":{"seconds":30}}

2. Dashboard

Muestra estado de enlace, batería, pantalla UI del T-Embed y accesos rápidos a plugins Xibalba (Sub-GHz, WiFi, NFC, IR, BLE, Wardriving).

Si hay actualización Xibalba disponible, aparece banner OTA → Tools → Flash.

La tarjeta de Hardening muestra TWDT, BOD, Secure Boot, Flash/NVS Encryption, Stack Canaries y Heap Poisoning reportados por el firmware.

Si hubo reset anormal, la app puede mostrar coredump pendiente y la última razón WDT/BOD expuesta por Xibalba.

Escaneo con scan_start / scan_stop. Perfiles BLE se guardan en la biblioteca local.

7. Wardriving (plugin wardriving)

  • start — opcional lat, lon
  • gps_update — actualización GPS desde el teléfono
  • stop, status

MapTools muestra puntos WiFi/BLE georreferenciados y panel Link Debug (200 líneas serial).

8. Consola TEH-Link

Envía JSON crudo con historial ↑↓. Chips rápidos: ping, get_info, subghz_tx, ir rx_start, nfc read.

Macros y perfiles usan pasos JSON TEH-Link (no CLI legacy).

9. Firmware Flash

Sección Xibalba oficial RECOMENDADO

Buscar releases GitHub → OTA USB (TEH-Link) o USB Flash con bootloader.

Tras una OTA correcta, la app confirma si el dispositivo marcó sha256_verified=true.

Sección Custom .bin

Solo USB Flash. Requiere aceptar disclaimer. Riesgo de brick.

10. Hardware Bringup

La app incluye accesos directos a la guía de pruebas de hardware, al script hardware_test_suite.ps1 y al checklist CSV del firmware Xibalba.

11. Backup y ajustes

  • Backup JSON: señales, IR, macros, perfiles (sin datos RF/GPS sensibles por defecto).
  • Ajustes: idioma, transporte USB/WiFi, re-emparejar TEH-Link, Hardware Bringup.

12. Solución de problemas
