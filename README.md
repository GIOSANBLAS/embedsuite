# EmbedSuite

Android companion app for **T-Embed Xibalba** firmware (TEH-Link over USB) and optional Bruce profile.

Package: `com.embedsuite.app`

## Build

Open in Android Studio and sync Gradle, or:

```bash
./gradlew assembleDebug
```
